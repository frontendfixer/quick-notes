# Writing in Quick Notes

Create a note with the **+** menu. Give it a title and start writing in the body. Use the formatting toolbar or right-click in the editor for formatting and clipboard commands. On a keyboard, **Shift+F10** also opens the editor menu.

## Type Markdown shortcuts

Press **Enter** to start a new paragraph after a heading. **Shift+Enter** inserts a line break inside the current paragraph or heading. Start block shortcuts at the beginning of a fresh paragraph. Press Enter twice at the end of a list to exit it.

| Type in the editor                             | What it does                               |
| ---------------------------------------------- | ------------------------------------------ |
| `#`, `##`, or `###` then Space                 | Heading 1, 2, or 3                         |
| `-` then Space                                 | Bulleted list                              |
| `1.` then Space                                | Numbered list                              |
| `[ ]` or `[x]` then Space                      | Unchecked or checked checklist item        |
| `>` then Space                                 | Block quote                                |
| `**bold**`, `*italic*`, or `~~strikethrough~~` | Format text as you type the closing marker |
| One backtick on each side of text              | Inline code                                |

Type checklist shortcuts directly as `[ ]` or `[x]`. A dash followed by Space starts a bullet list immediately. You can also select **Checklist** in the formatting toolbar.

Select text to apply **bold**, _italic_, underline, highlight, strikethrough, inline code, or a link. The toolbar also has headings, lists, quotes, code blocks, a divider, Undo, and Redo. Paste an image or a supported image URL into the editor to insert it.

## Paste or copy Markdown

Copy your Markdown draft, then right-click in the note and choose **Paste as Markdown**. A pasted checklist uses a dash before each checkbox. Markdown paste also supports tables, links, and fenced code blocks.

```markdown
## Release checklist

- [x] Review the draft
- [ ] Share the release notes

[Release page](https://example.com)

| Task          | Owner |
| ------------- | ----- |
| Release notes | Priya |
```

Use **Copy as Markdown** to copy your selection or, with no selection, the whole note body.

## Organize and share

- **Folders.** Create folders from the **+** menu. Use the note menu to move a note between folders or back to the main list.
- **Pins and search.** Pin important notes to keep them at the top. Use search to find synced notes in the current collection. Use **Sort notes** to switch between last edited and title order.
- **Archive and Trash.** Archive finished notes or move notes to Trash. Both collections are in the Account menu. You can restore trashed notes or permanently delete them there.
- **PDF and print.** Use the note menu to download a PDF or print the note.

## Save and recover

**Saved on device** means your draft is stored in this browser. **Saved to server** means it has synced. You can edit locally saved and recently cached notes while offline. If another device changes the same note, compare the two versions and choose how to resolve the conflict. Use **Account → Download drafts** when you need a local copy of unsynced work.

This guide is read-only. You can remove its pinned entry and reopen it whenever you need it from **Account → Writing in Quick Notes**.
